# Rekapitulasi Pengujian Beta Testing (User Acceptance Testing - Guru & Staf TU)

Pengujian **Beta Testing / User Acceptance Testing (UAT)** dilakukan secara langsung kepada **11 Guru Mata Pelajaran / Wali Kelas** dan **1 Staf Tata Usaha (TU) / Admin** di sekolah untuk mencoba fitur-fitur presensi GPS, monitoring lokasi siswa, rekap absensi, dan pengajuan izin sakit.

---

## 1. Aspek Penilaian Kuesioner
Setiap guru dan staf memberikan penilaian dengan skala nilai 1 sampai 5:
- **Tampilan (UI/UX)**: Kemudahan tampilan saat dibuka di HP/Laptop.
- **Fitur & Validasi (Fungsionalitas)**: Ketepatan deteksi lokasi GPS sekolah (Haversine), pencegahan absen di luar radius, dan rekap otomatis.
- **Kinerja (Kecepatan)**: Kelancaran sistem saat dipakai jam sibuk pagi hari.

*(1 = Sangat Kurang, 2 = Kurang, 3 = Cukup, 4 = Bagus/Puas, 5 = Sangat Bagus/Sangat Puas)*
