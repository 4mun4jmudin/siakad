# Pengujian System Usability Scale (SUS)

Pengujian **System Usability Scale (SUS)** digunakan untuk mengukur tingkat kebergunaan (*usability*) dan penerimaan pengguna akhir terhadap prototipe sistem presensi SIAKAD. Kuesioner ini disebarkan kepada seluruh **Siswa Kelas 10** sebagai responden utama.

---

## 1. Instrumen Kuesioner (10 Pertanyaan Standar SUS)

Setiap siswa kelas 10 dimihnta untuk memberikan p ensaasasnns ysilaian dengan skala Likert 1-5:
*(1 = Sangat Tidak Setuju, 2 = Tidak Setuju, 3 = Ragu-ragu, 4 = Setuju, 5 = Sangat Setuju)*

|     Kode     | Pertanyaan Kuesioner                                                                    |  Sifat  |
| :-----------: | :-------------------------------------------------------------------------------------- | :-----: |
| **Q1** | Saya pikir saya akan sering menggunakan sistem presensi ini.                            | Positif |
| **Q2** | Saya merasa sistem presensi ini terlalu rumit padahal bisa dibuat lebih sederhana.      | Negatif |
| **Q3** | Saya merasa sistem presensi ini mudah digunakan.                                        | Positif |
| **Q4** | Saya merasa butuh bantuan teknisi/guru untuk bisa menggunakan sistem ini.               | Negatif |
| **Q5** | Saya menemukan bahwa berbagai fungsi di sistem ini terintegrasi dengan baik.            | Positif |
| **Q6** | Saya merasa ada banyak hal yang tidak konsisten pada sistem ini.                        | Negatif |
| **Q7** | Saya merasa mayoritas siswa dapat belajar menggunakan sistem ini dengan sangat cepat.   | Positif |
| **Q8** | Saya merasa sistem presensi ini sangat tidak praktis / merepotkan untuk digunakan.      | Negatif |
| **Q9** | Saya merasa sangat yakin pada diri saya sendiri saat menggunakan sistem ini.            | Positif |
| **Q10** | Saya harus banyak belajar hal baru terlebih dahulu sebelum bisa menggunakan sistem ini. | Negatif |

---

## 2. Aturan Perhitungan Skor SUS

Untuk menghitung skor SUS, digunakan rumus standar baku:

- **Pertanyaan Ganjil (Q1, Q3, Q5, Q7, Q9):** Skor aktual dikurangi 1 `(Skor - 1)`.
- **Pertanyaan Genap (Q2, Q4, Q6, Q8, Q10):** Angka 5 dikurangi skor aktual `(5 - Skor)`.
- **Skor SUS Individual:** Jumlah seluruh hasil perhitungan di atas dikalikan dengan **2,5**.
