Nah bro, kalau **Rekapitulasi Nilai** itu beda dengan halaman input nilai.

Kalau:

* **Penilaian** = tempat guru input nilai
* maka:

  👉 **Rekapitulasi Nilai** = tempat melihat hasil akhir dan analisa nilai.

Halaman ini sangat penting untuk:

* admin,
* wali kelas,
* kurikulum,
* kepala sekolah.

Karena di sinilah semua data nilai diringkas.
